# Grupo 3 — Frontend

Bienvenido a tu repositorio de frontend. A partir de aquí pueden comenzar a trabajar en sus proyectos de taller.

## Vistas desarrolladas

### Perfil de Usuario
Vista inicial desarrollada en HTML y CSS a partir del wireframe de baja fidelidad proporcionado por el equipo UX/UI.

### Perfil de Mascota
Vista inicial desarrollada en HTML y CSS a partir del wireframe de baja fidelidad proporcionado por el equipo UX/UI. Incluye la estructura base para los datos de la mascota, información general, historial médico y registro de vacunas.
