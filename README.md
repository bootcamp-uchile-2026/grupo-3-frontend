# Grupo 3 — Frontend

## Descripción del proyecto

Este repositorio contiene el desarrollo Frontend del proyecto realizado por el Grupo 3 para el Taller de Bootcamps.

La aplicación está orientada al desarrollo de una plataforma relacionada con servicios y productos para mascotas.

Durante el Hito 1, el desarrollo Frontend se realiza inicialmente utilizando HTML y CSS, tomando como base los wireframes de baja fidelidad definidos por el equipo UX/UI.

---

## Tecnologías utilizadas

Actualmente se utilizan las siguientes tecnologías y herramientas:

- HTML5
- CSS3
- Git
- GitHub
- Visual Studio Code
- Live Server

## Vistas desarrolladas

### Perfil de Usuario
Vista inicial desarrollada en HTML y CSS a partir del wireframe de baja fidelidad proporcionado por el equipo UX/UI.

### Perfil de Mascota
Vista inicial desarrollada en HTML y CSS a partir del wireframe de baja fidelidad proporcionado por el equipo UX/UI. Incluye la estructura base para los datos de la mascota, información general, historial médico y registro de vacunas.

### Agendar Veterinario - Profesional

Vista desarrollada en HTML y CSS a partir del wireframe de baja fidelidad proporcionado por el equipo UX/UI. Incluye la selección de profesionales veterinarios, indicador de pasos del proceso de agendamiento, resumen de la consulta y botón de confirmación.

### Agendar Veterinario - Datos de contacto

Vista desarrollada en HTML y CSS a partir del wireframe de baja fidelidad proporcionado por el equipo UX/UI. Incluye formulario de datos de contacto, campos obligatorios, sección opcional de comentarios u observaciones, indicador de pasos del proceso de agendamiento, resumen de la consulta y botón para agendar.

Ejecución del proyecto

Para visualizar las vistas durante el desarrollo:

Clonar el repositorio.
Abrir el proyecto en Visual Studio Code.
Abrir el archivo HTML correspondiente a la vista que se desea visualizar.
Ejecutar el archivo utilizando la extensión Live Server.
La vista se abrirá en el navegador para su revisión.
Flujo de trabajo con Git

El equipo utiliza ramas para mantener organizado el desarrollo del proyecto.

La rama main se mantiene como rama principal del repositorio.

La rama develop se utiliza como rama de integración del trabajo realizado durante el desarrollo.

Las nuevas funcionalidades o vistas se desarrollan en ramas independientes utilizando el prefijo feature/.
